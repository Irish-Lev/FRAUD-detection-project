What the data told us

Dataset Facts
Source Sparkov · Kaggle — simulated US payment transactions
Volume 1.3M transactions · Jan 2019 – Dec 2020
Fraud 0.58% rate · 7,506 fraud cases in training set
Split Time-based 80/20 — no data leakage · 1.03M train / 259K test
Columns amount, merchant, category, lat/long, dob, trans_time
Key EDA Findings
0–4 am: 5× higher fraud rate than daytime — prime card-testing window
shopping_net: highest fraud rate by category — card-not-present transactions dominate
geo_distance_km: fraudulent transactions average 3× further from cardholder's home address
Amount: bimodal — fraud clusters at micro ($1–$10 card-testing) and large ($500+)

Three approaches, one winner

Same held-out test set · Primary metric: PR-AUC (not ROC-AUC — optimistic on 0.58% imbalance)

BASELINE
Logistic Regression
Linear classifier · simple reference point · no ensemble, no embeddings
PR-AUC 0.2387 ROC-AUC 0.9023 Explainable ✓
PRIMARY · WINNER
XGBoost + FinBERT
46 features (16 engineered + 30 FinBERT PCA embeddings) · SMOTE on train only · n_estimators=300
PR-AUC 0.8462 ROC-AUC 0.9966 SHAP ✓
DEEP LEARNING
1D CNN (Keras)
2× Conv1D layers · class_weight (not SMOTE) · built from scratch in TensorFlow
PR-AUC 0.7588 ROC-AUC 0.9836 Limited XAI
XGBoost wins. Tabular features have no natural spatial ordering — CNNs excel at sequential data. Under EU PSD2, SHAP explainability is non-negotiable. PR-AUC is the right metric because ROC-AUC inflates on imbalanced classes.
